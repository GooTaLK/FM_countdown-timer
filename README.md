# Launch countdown challenge

This is a simple countdown challenge, provided by [Frontend Mentor Challenge](https://frontendmentor.io), that tests your ability to work with loops, timing in programming and animations.

## Created with

No frameworks, just plain:

- HTML
- CSS
- JavaScript

## Features

- Countdown timer that counts down to a specific date and time.
- Responsive design that works on both desktop and mobile devices.
- User-friendly interface with clear display of days, hours, minutes, and seconds remaining.
